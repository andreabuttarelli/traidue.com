# i18n Design — traidue.com

**Date:** 2026-03-11
**Status:** Approved
**Languages:** Italian (default), English, Spanish, Portuguese

## Decisions

- **Library:** Paraglide JS (official SvelteKit i18n, compiler-based, type-safe)
- **URL structure:** Prefix-based. IT has no prefix (default), others use `/en/`, `/es/`, `/pt/`
- **Slugs:** Translated per language (SEO-optimized)
- **Content scope:** ALL articles (~90), quizzes, glossary, UI, static pages
- **Regional content:** UI translated, data stays Italian (useful for international users)

## URL Schema

| Lang | Wiki Example | Quiz | Homepage |
|------|-------------|------|----------|
| IT | `/wiki/disforia-di-genere` | `/quiz/identita-genere` | `/` |
| EN | `/en/wiki/gender-dysphoria` | `/en/quiz/gender-identity` | `/en` |
| ES | `/es/wiki/disforia-de-genero` | `/es/quiz/identidad-genero` | `/es` |
| PT | `/pt/wiki/disforia-de-genero` | `/pt/quiz/identidade-genero` | `/pt` |

## Content Structure

### Wiki Articles

From: `src/content/wiki/{category}/{slug}.md`
To: `src/content/wiki/{lang}/{category}/{slug}.md`

Frontmatter additions:
```yaml
lang: it
translationKey: gender-dysphoria  # shared key linking all translations of same article
```

### Quiz Files

From: `src/lib/data/quiz/{slug}.json`
To: `src/lib/data/quiz/{lang}/{slug}.json`

### Glossary

From: `src/lib/data/glossary.ts` (single file)
To: `src/lib/data/glossary/{lang}.ts` (per language)

### UI Strings (Paraglide)

```
messages/it.json   (extracted from current hardcoded Italian text)
messages/en.json
messages/es.json
messages/pt.json
```

## Routing

Paraglide handles locale prefix automatically via URL strategy. Default locale (IT) has no prefix.

Content loading functions become locale-aware:
```typescript
getAllArticles(lang?: string): WikiArticle[]
getArticleBySlug(slug: string, lang?: string): WikiEntry | null
getTranslations(translationKey: string): Record<string, WikiArticle>
```

Static pages (chi-siamo, famiglie, giovani, etc.) use Paraglide messages — no separate files per language.

## SEO

- **hreflang:** All 4 languages + x-default (IT) on every page
- **og:locale:** Dynamic per language (it_IT, en_US, es_ES, pt_BR)
- **`<html lang>`:** Set dynamically
- **Sitemap:** URLs for all languages with `xhtml:link` alternates
- **OG images:** Generated per language (translated title/category text)
- **Schema.org:** `inLanguage` field, translated content in properties
- **Canonical:** Each language version has its own canonical URL

## UI Components

### Language Switcher (new, in Navbar)
- Dropdown with language codes (IT, EN, ES, PT)
- If current page has translation → navigate to translated version
- If no translation exists → navigate to target language homepage
- Uses `translationKey` for mapping

### Updated Components
- **Navbar:** Translated links via Paraglide messages
- **Footer:** All strings extracted to Paraglide messages
- **WikiLayout:** Reading time label, date formatting, category labels translated
- **ShareButtons:** Share text translated per language
- **SearchInput:** Placeholder translated, results filtered by current language
- **SEO.svelte:** Dynamic hreflang, og:locale, canonical per language
- **StructuredData.svelte:** inLanguage field, translated properties
